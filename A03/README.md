## Run

Open the notebook in Google Colab with a free CPU runtime. Add an existing OpenAI key to Colab Secrets as `OpenAI` or `OPENAI_API_KEY` and enable notebook access. Never put a credential in source control. Run setup, core and offline checks, then the explicitly marked paid experiment cell. For custom inputs, enable the interactive cell and enter integer `(n,i)` values. Each request predicts the square of the previous GPT integer; Python checks that local product and independently tracks the original correct sequence. An invalid text response stops that case. API and formatting failures do not count as verified arithmetic failures.
